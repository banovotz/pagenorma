A voucher code gives you free tokens.

## Where to redeem

**On the Dashboard**

1. In the allowance card, click **I have a voucher**.
2. Enter the code and click **Redeem voucher**.

**On the Profile page**

1. Open **Profile** and find **Voucher code** under **Analysis tokens**.
2. Enter the code and click **Redeem voucher**.

On success you will see *Voucher redeemed. 10 token(s) added to your balance.* (the number depends on the voucher).

## Rules

- Each voucher can be redeemed **once per account**.
- Codes are not case-sensitive, and spaces around them are ignored.
- You must be signed in and have a verified email.
- Some vouchers expire or have a limit on how many people can use them.

## Messages

| Message | What to do |
|---|---|
| *Enter a voucher code.* / *Enter a valid voucher code.* | The box is empty or the code is malformed. Check it. |
| *This voucher code is not valid.* | Check for typos. The code may have expired. |
| *You have already redeemed this voucher.* | It was used on your account already. |
| *This voucher has reached its redemption limit.* | It is no longer available. |
| *Verify your email address before redeeming a voucher.* | See [Verify your email address]({% link support/account/verify-your-email.md %}). |
| *Sign in before redeeming a voucher.* | Sign in and try again. |
