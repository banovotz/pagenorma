Open **Translation Analyses** to see **Saved Translation Analyses**. Each card shows the project title and the date of the analysis.

## Open an analysis

Click **Open Analysis**. The link in your browser's address bar identifies the analysis, so the **Back** button takes you back to the list.

## Delete an analysis

1. Click **Delete** on the card.
2. Confirm *Are you sure you want to delete this saved analysis?*

Deleting an analysis does not delete the project, and it does not give back any allowance you spent on it.

## Good to know

- Analyses are saved in your browser, together with your projects, so they are included in a [backup]({% link support/data/back-up-and-restore.md %}).
- If the list says **No saved analyses found**, you have not run one yet. See [Run an AI analysis]({% link support/analysis/run-an-analysis.md %}).
- A card labelled *Project ID: …* belongs to a project you have since deleted.
