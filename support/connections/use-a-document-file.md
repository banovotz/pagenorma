If you write in Word, LibreOffice or a text editor, you can use the file itself as the translation source.

## Choose the file

1. Open the project form and switch to the **Document file (docx/rtf/odt/txt)** tab.
2. Click **Choose file with change tracking**, or use the file field above it.
3. Select your document. The form shows *Selected file* with its name.
4. Click **⚡ Fetch Data from ePub/PDF & Translation**, then **Save Project**.

The selected document is saved with the project, so it stays available for analysis.

## What "change tracking" means here

In browsers that support it (such as Chrome and Edge), **Choose file with change tracking** lets pagenorma remember where the file is on your computer. When you click **Refresh Translation**, it reads the updated file from the same place, with no need to select it again.

In other browsers, or if you use the plain file field, **Refresh Translation** asks you to select the updated file each time.

## Tips

- Save your document before refreshing, so the latest text is included.
- Supported formats are DOCX, RTF, ODT and TXT.
- If you move or rename the file, choose it again from **Edit**.
