## Edit a project

1. Click **Edit** on the project card. The project form opens with the current values.
2. Change what you need: title, client, rate, dates, daily target, weekends, translation language, or the source and translation files.
3. Click **Save Project**, or **Cancel** to close the form without saving.

If you leave the Dashboard while the form is open, it closes by itself.

## Delete a project

1. Click **Delete** on the project card.
2. Confirm the message *Are you sure you want to delete this project and all its entries?*

> Deleting cannot be undone. [Export a backup]({% link support/data/back-up-and-restore.md %}) first if you might need the project again.

## What happens to the saved analysis?

A saved analysis is stored separately from the project. After you delete a project, its analysis may still appear on the **Translation Analyses** screen, labelled with the project's ID instead of its title. Delete it there if you no longer need it. See [Manage saved analyses]({% link support/analysis/manage-saved-analyses.md %}).
