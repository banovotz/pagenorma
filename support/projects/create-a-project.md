A project holds one book: its source text, your translation, your rate and your deadline.

## Steps

1. On the **Dashboard**, click **New Project**.
2. Under **Select source ePub or PDF**, choose the original book. See [Supported file formats]({% link support/projects/supported-file-formats.md %}).
3. Choose where your translation lives:
   - the **Translation Google Doc** tab, then **Choose Google Doc…** — see [Connect Google Docs]({% link support/connections/connect-google-docs.md %}), or
   - the **Document file (docx/rtf/odt/txt)** tab — see [Use a document file]({% link support/connections/use-a-document-file.md %}).
4. Optionally set **Translation language (for AI commentary)**. Leave it on **Auto-detect (recommended)** unless the language is detected wrongly.
5. Click **⚡ Fetch Data from ePub/PDF & Translation**. pagenorma reads both texts, then shows the number of characters and approximate standard pages for each. It also fills in the title and cover when it can, and suggests the source page count.
6. Fill in the project details (fields marked * are required):

| Field | Notes |
|---|---|
| **Book Title / Project Name** * | Filled from the source file when empty. |
| **Client / Publisher** | Shown on the card and in Financial Analytics. If empty, the card says *Independent project*. |
| **Source Standard Pages** * | 1800 characters = 1 page. Filled in for you; you can correct it. |
| **Rate per Page (€)** * | Your fee per standard page. |
| **Start Date** * and **Target Deadline** * | Used for pace and monthly earnings. |
| **Daily Target (Pages/day)** | Your planned pace. Optional. |
| **Work on Weekends?** | **No** counts business days only; **Yes** counts all calendar days. |

7. Click **Save Project**.

Your project appears on the Dashboard. It is stored in your browser, not on a server.

## Good to know

- If the source file cannot be processed, pagenorma saves the project without source text and tells you. You will need to select the file again before you can run an analysis.
- Amounts are shown in euros.
