pagenorma keeps a copy of your translation. When you have written more, refresh the project so progress, pace and earnings catch up.

## Steps

1. On the Dashboard, find the project card.
2. Click **Refresh Translation**.

What happens next depends on where the translation comes from.

- **Google Doc** — pagenorma reads the current text of the document. If Google reports that access was denied, pick the document again with **Choose Google Doc…** from the project's **Edit** screen.
- **Document file** — if you originally chose it with **Choose file with change tracking**, pagenorma reads the updated file at its original path. Otherwise it asks you to select the updated file. See [Use a document file]({% link support/connections/use-a-document-file.md %}).

When it finishes, the card shows the new character count, progress and earnings.

## Good to know

- Refreshing does not re-run the AI analysis. To check the new text, run **Analyze Text** again.
- Save your document in your word processor before refreshing, so the latest changes are included.
- If a project has no translation source, you will see *This project does not have a translation source configured*. Open **Edit** and add one.
